What to point out while teaching

Broken return

The outer function finishes before its timer callback runs. Its immediate return value is undefined.

Callback

Pass a function now. The timer calls it later with the prepared tea.

Promise

prepareTea(order) immediately returns a Promise. It settles when the order becomes ready or fails.

Async / await

await prepareTea(order) pauses only that order's async function. Other orders can be accepted.
